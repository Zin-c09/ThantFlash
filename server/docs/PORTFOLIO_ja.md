# ポートフォリオ紹介：ThantFlash

> 履歴書・ES・面接での説明用。自分の言葉に直して使ってください。

## 一言で

**JLPT の勉強のために自分で作った、間隔反復型フラッシュカードアプリの REST API** です。
Java 21 と Spring Boot 3 で開発しました。

## 作った理由

日本語能力試験 N2 の単語・漢字を覚えるため、最初は HTML/JavaScript だけでブラウザ上で動くアプリを作りました。
しかしデータがブラウザ内にしか保存されず、スマートフォンとパソコンで共有できないという課題がありました。
そこで、学校で学んでいる Java と Spring Boot を使ってサーバー側を作り、
ユーザー登録・データ保存・学習統計ができるようにしました。

## 機能

- ユーザー登録・ログイン（JWT 認証）
- デッキ・カードの作成／編集／削除／検索
- 忘却曲線に基づく復習日の自動計算（SM-2 アルゴリズム）
- Anki 形式（TSV）ファイルの一括インポート
- 学習統計（今日の復習数、連続学習日数、正答率、直近 7 日の推移）

## 使用技術

Java 21 / Spring Boot 3.5 / Spring Security / Spring Data JPA / PostgreSQL / H2 / Flyway /
JUnit 5 / MockMvc / Swagger (OpenAPI) / Docker / GitHub Actions

## 工夫した点

1. **他ユーザーのデータを見られないようにした**
   すべての取得処理で「ログイン中のユーザーの物か」を確認し、他人のデータには 404 を返します。
   403 ではなく 404 にしたのは、データが存在すること自体を知られないためです。この動作は自動テストで確認しています。

2. **テストしやすい設計**
   現在時刻を直接取得せず `Clock` を注入し、復習日の計算は DB に依存しない独立したクラスにしました。
   単体テストと結合テストを合わせて 17 件あり、GitHub Actions で push のたびに自動実行されます。

3. **DB の変更履歴を管理**
   Flyway でテーブル定義をバージョン管理し、Hibernate は検証のみ（`ddl-auto: validate`）にしました。
   開発は H2、本番は PostgreSQL と、同じ SQL で両方動くようにしています。

4. **設計書を書いた**
   ER 図・API 一覧・シーケンス図を [`DESIGN.md`](DESIGN.md) にまとめました。

## 苦労した点・学んだこと

- Spring Security の設定（JWT の発行と検証の流れ）を理解するのに時間がかかりましたが、
  外部ライブラリを増やさず Spring 標準の仕組みで実装できました。
- JPA で一覧を取得すると SQL が大量に発行される（N+1 問題）ことを知り、`join fetch` や集計クエリで解決しました。

## 今後の予定

- Web 画面から API を呼び出し、端末間で同期できるようにする
- クラウド（AWS など）へのデプロイ
- Testcontainers を使った PostgreSQL での自動テスト
